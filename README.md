# 我的第一个 GitHub 仓库

这是我的第一个代码仓库，用来走通 `新建 → 提交 → 推送` 的完整流程。

## 这个仓库里有什么

- `README.md`：就是你现在看到的这份说明文件
- `hello.py`：一个最简单的 Python 脚本
- `.gitignore`：告诉 git 哪些文件不需要上传

## 怎么运行

```bash
python hello.py
```

## 学习笔记

- **仓库（Repository）**：一个项目，包含代码和它的全部修改历史
- **提交（Commit）**：一次存档，记录你改了什么
- **推送（Push）**：把本地的存档上传到 GitHub
- **拉取（Pull）**：把 GitHub 上的更新下载到本地
